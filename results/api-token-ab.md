# API 级 Token A/B 结果

日期：2026-08-13

## 结论

设计目标“平均减少至少 70% Token”未达成。

- 六场景原始合计：A `7,595,417` Token，B `3,943,542` Token，降低 `48.08%`。
- 排除质量失败的动画场景 5：A `6,047,325`，B `3,378,048`，降低 `44.14%`。
- API 耗时合计：A `2,187.16s`，B `1,097.30s`，降低 `49.83%`。
- 工具调用合计：A `309`，B `182`，降低 `41.10%`。

因此不能宣称 70% Token 目标完成，也不能据此进入 Beta 发布。

## 实验协议

- 同一代理：Codex CLI `0.142.3`。
- 同一模型：`gpt-5.4`，reasoning effort `high`。
- 每个臂均为独立 ephemeral 会话；相同任务文本、素材和质量门槛。
- A 臂：现有 `pptx` skill；创建走 PptxGenJS，编辑走 unpack/edit/clean/pack。
- B 臂：只允许 `dist/ppt-agent.exe` 的 inspect/diff/create/apply/qa/render。
- Token 来自每次 Codex JSONL 的 `turn.completed.usage`，总量口径为 `input_tokens + output_tokens`。`cached_input_tokens` 是 input 的子集，不重复相加；`reasoning_output_tokens` 是 output 明细，也不重复相加。
- 原始 JSONL、stderr、PPTX 和 usage 位于忽略目录 `results/local/token-api/api-gpt54-final/`。
- `usage.json` SHA-256：`DCF4CE7BAD8CA0FBB9470B70AA59DC86DE34FFF6DD7DE71E7C166EB4B7BC6145`。

之所以固定 `gpt-5.4`：当前可执行的新 CLI 能返回 usage，但其工具宿主缺失；可正常调用本机工具的 CLI 版本不支持 `gpt-5.6-sol`。两臂仍保持完全相同的模型和运行时。

## 质量证据

- WPS 12.0 成功回开 12/12 个输出。
- 独立视觉 QA 检查 12 个目录、56 张 WPS 渲染图；静态画面全部通过，无白页、裁切、重叠或内容缺失。
- 场景 2 两臂均为 4 页，表格更新为“测试 / 11/11 / 全通过”，三张图表保留，assignment QA 0/0。
- 场景 3 两臂图片媒体 SHA-256 均与 replacement 一致，标题右移至 x=0.95，presentation QA 0/0。
- 场景 4 两臂均无小于 14pt 的正文 run，形状未越界，presentation QA 0/0。
- 场景 6 两臂均保留人工标题，续改标题位于 x=1.05，presentation QA 0/0。
- 场景 5 输入夹具没有动画；A、B 输出各有 10 个效果。B 臂生成了 4 条操作（对象动画 + paragraph 1/2/3），而 WPS 的 paragraph level 本身会展开逐段效果，造成重复。该问题属于代理生成 patch 的语义错误，本轮不把它伪装成成功。

## 解读

`ppt-agent` 对从零创建和动画类任务明显降低上下文与工具成本，但优势不稳定：已有稿精确修改仅降低 22.19%，排版诊断反而增加 31.89%。六场景总降幅为 48.08%，距离 70% 目标仍差 21.92 个百分点。

这是一轮单次配对实验，不包含方差。若未来复测，应固定支持当前模型的同一 CLI 版本，并对每个场景进行多次独立重复；在此之前，48.08% 是当前唯一可审计的 API 级结论。

## A 基线复用

本轮 A 臂已由 `acceptance/ab/api-token-a-baseline.json` 封存。清单固定模型、推理档位、完整实验文本、六场景输入、A 输出、事件日志及官方 usage 的哈希。以后执行 `tools/run_api_token_ab.py --run-id <新目录名>` 时只调用 B；B 的素材直接复制自本轮 A 输入快照，A 的计量行以 `source: frozen_a_baseline` 写入新一轮 `usage.json`。

任何协议漂移、Codex CLI 版本变化、A 证据缺失或哈希不一致都会在 API 调用前终止。因此可以省掉重跑 A 的时间和费用，但新结果的统计含义仍是“新 B 对比 2026-08-13 的固定 A”，不是同一时点重新随机配对的 A/B。

v0.2 Agent 接口减负后的 B-only 回归见 `results/api-token-b-interface-v02.md`：首轮 Token 指标达到 71.06%，但当时动画场景失败；后续场景 5 定向修复已通过。六场景各三次独立复测尚未执行，因此仍不能宣称结果稳定。
