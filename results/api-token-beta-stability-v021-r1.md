## 调用失败审计

本轮共有 13 次非零命令退出：

- `6` 次 PowerShell here-string 向 `apply ... -` 传递 JSON 后，子进程收到空 stdin，返回 `INVALID_PATCH`。这说明 CLI 的 stdin 能力存在，但当前 Agent 命令执行包装不适合用 here-string 内联 JSON。
- `4` 次场景 6 定向 inspect 使用 `slide.number`、`slide.title`；v0.2.1 当时尚未接受这两个自然别名，返回 `INVALID_INSPECT_FIELDS`。
- `1` 次场景 3 把实验规则中的中文动词“查询”误解为字面操作 `query`，调用 `schema apply --op query`。
- `2` 次 apply 在文档含外部关系时未先传 `--allow-risk external_relationship`，安全策略按设计阻断且文档未改变。

因此，上一轮 11 次错误并未在本轮归零，只是错误形态发生了变化。不能仅凭最终 Agent 返回码为 0 或输出文件存在，就把“零错误调用”记为通过。

## 本轮后追加的确定性修正（未再次调用 API）

根据失败事件流，已做最小协议修正：
